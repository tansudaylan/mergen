# mergen

mergen is an experimental unsupervised-learning framework for anomaly detection and classification of time-series data.

## Status

This repository is research-grade and dependency-heavy. It depends on significant machine-learning infrastructure, especially TensorFlow and related visualization tooling, and is not part of the minimal active core stack used for the maintained scientific workflow packages.

It remains available for historical and experimental use, but it should be treated as an isolated research pipeline rather than a lightweight shared library.
